## 排查表结论

| 原排查项 | 结论 | 处理结果 |
| --- | --- | --- |
| 底部导航与安全区 | 已解决 | 统一底部导航安全区规则，内容与系统导航区保持至少 28vp 间距；顶部、底部安全区背景跟随主题。 |
| 浅色模式对比度 | 已解决 | 页面正文、次要文本、边框、选中态和操作按钮统一使用语义色。 |
| 提醒保存状态误导 | 已解决 | 未开通代理提醒能力时明确提示“提醒未生效”，不再显示成功保存。 |
| 应用图标不一致 | 已解决 | AppScope、entry、桌面/最近任务统一 layered icon，前景与背景图层字节一致。 |
| 应用名称不具识别性 | 已解决 | 统一使用“元气有数”，副标题为“喝水、记账与生活管理”。 |
| 状态栏遮挡 | 已解决 | 使用沉浸式窗口动态安全区，状态栏图标对比度随主题切换。 |
| 小于 10fp 文本 | 已解决 | 生产代码静态检查未发现小于 10fp 的 fontSize。 |
| 首页/账本/统计/设置布局 | 已解决 | 合并为四个主入口：概览、喝水、账本、我的；账本主界面使用可用宽度和响应式断点。 |
| 深色模式适配 | 已解决 | 主页面、账本主界面及统计/预算/分类/记账输入等子页面使用语义深色色板，不只切换背景。 |
| 原排查表中的其他应用功能 | 不适用 | 当前 bundle 不包含默认视图列表、节假日快速添加、除夕日期、专注重置、白噪音多轨等功能。 |
