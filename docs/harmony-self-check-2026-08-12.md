## 结论

本轮已修复可在工程内确认的问题：移除未参与计算的年龄、性别和身高采集；保留旧资料/备份兼容读取并在新写入时清除旧字段；将已确认的小交互区域提升到强制下限 `40vp x 40vp`；修正两条与当前产品不一致的自检脚本断言。

工程静态契约、Hypium 和 release 构建均通过，API 22 手机模拟器上的代表页面与弹窗能够正常显示和操作。当前没有确认但尚未修复的本地代码级强制问题。

该结论不等于可直接提交 AppGallery。按开发者决定，隐私政策、同意/撤回机制和 AppGallery Connect 隐私标签将在上架时补充，因此隐私结论保持 `partial`。此外，AGC 元数据、分类、备案、资质、正式发布 Profile、平板、多窗和性能量化仍未验证。

## 修复摘要

- 当前 `UserProfile` 只保存昵称、头像、体重、运动量、特殊状态、气候、目标及必要状态字段。
- 旧 JSON 中的 `age`、`gender`、`heightCm` 仍可读取；`cloneUserProfile()` 和 `saveProfile()` 不再写回这些字段。
- 引导页不再收集年龄和性别；个人资料页不再收集年龄、性别和身高。
- 新增 `recommendedTouchTargetSize = 48` 与 `minimumTouchTargetSize = 40`，并用于分段控件、饮水量预设、统计/成就入口、饮品操作、资料选择项和账本分类控件。
- 通知/提醒代码和通知权限均不存在时，自检按 `not applicable` 处理。
- 用户协议检查只要求存在“协议变更”内容，不再错误绑定固定章节号。
