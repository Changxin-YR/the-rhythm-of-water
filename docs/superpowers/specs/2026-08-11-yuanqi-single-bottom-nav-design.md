# 元气有数：单一底部导航与账本页面整合设计

日期：2026-08-11  
状态：已获用户确认，进入实施

## 目标

把 WaterReminder 与 JiZhangBen 统一成一个正常的中文应用“元气有数”，只保留一套底部主导航，避免账本页再次出现一套顶部 TabBar。饮水、账本、统计、分类、预算、提醒、主题和数据管理保留原有能力，但按业务域重新组织，降低页面层级和重复入口。

## 导航与信息架构

底部主导航固定为四项：

1. **总览**：今日饮水进度、连续达标、本月收支摘要、快捷记录和最近活动。
2. **喝水**：饮水记录、目标、提醒、饮品、植物、成就和历史统计。
3. **账本**：本月收支摘要、今日交易、记一笔，以及四个工具入口：交易记录、月度统计、分类管理、月预算。
4. **我的**：用户资料、目标与提醒、饮品/植物、外观主题、数据管理、协议与关于。

账本页面只渲染一个内容页，不再渲染“首页 / 账单 / 统计 / 设置”内部 Tabs。原 Tabs 中的能力迁移为页面内工具入口或统一“我的”设置入口：

- BillsTab 的交易列表抽取为“交易记录”入口；
- StatisticsTab 继续使用现有 LedgerStatisticsPage；
- 分类与预算继续使用现有 LedgerCategoryManagePage、LedgerBudgetPage；
- SettingsTab 不再作为账本内第二份设置，数据、导出、主题和协议归入统一设置页面。

## 视觉与交互

- 延续参考 UI 的晨雾蓝、海盐白、深海靛色视觉，但使用统一的语义色牌，不允许业务页硬编码纯白或纯黑。
- 卡片使用统一圆角、间距、阴影和边框；账本工具卡与饮水快捷卡采用同一组件语言，仅通过图标和语义色区分业务。
- 深色模式同步切换背景、卡片、文本、分割线、输入框、空状态、图标底色、收支颜色、底部导航和系统安全区背景。
- 交互反馈保持现有本地数据服务和刷新总线：新增、编辑、删除、导入、导出、重置后发布统一刷新版本号，返回页面即可看到最新摘要。
- 页面内容使用安全区 inset，底部导航与系统安全区颜色保持一致，内容不侵入状态栏和底部手势区。

## 功能边界

- 继续使用 SDK/target 22、单机本地存储，不新增网络依赖或网络权限。
- 不删除账本核心数据模型和服务；只调整入口和页面组合。
- 不新增重复的设置、关于、数据管理或协议页面；旧页面保留必要路由兼容，但不在主导航中重复展示。

## 验收标准

- 主页面只有一条底部四项导航；账本内容中不存在第二条顶部 Tabs。
- 账本工具入口可分别进入交易记录、月度统计、分类管理和月预算，原有新增/编辑/删除能力可用。
- 总览、喝水、账本和我的四个一级页面在浅色、深色模式下均无白块/黑字对比异常，状态栏和安全区颜色一致。
- 现有 Hypium 测试、debug/release HAP 构建和排查表静态审计继续通过。
