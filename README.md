# 元气有数

元气有数是一款使用 ArkTS 与 ArkUI 开发的 HarmonyOS 原生健康管理应用，融合科学饮水管理与个人记账，帮助用户记录每日饮水、管理日常收支并通过可视化数据了解自己的生活状态。应用以本地离线运行为主，不依赖登录和云端服务。

## 核心功能

- 根据个人信息计算每日饮水目标，支持白水、茶、咖啡、牛奶、果汁等饮品记录。
- 提供快捷饮水、任意容量输入、常用杯具和自定义饮品配置。
- 支持饮水记录编辑、删除、撤销、目标进度和历史统计。
- 提供个人记账、账单分类、预算、统计图表和账单详情功能。
- 支持首页概览、成就、植物成长、个人资料、数据备份与恢复。
- 支持系统主题、深色模式、响应式布局和多设备适配。

## 技术与隐私

- ArkTS、ArkUI、Stage 模型。
- Preferences 与本地数据库持久化数据。
- 饮水记录、账单和个人设置保存在设备本地。
- 不要求登录，不上传用户的健康数据和账单数据。

## 构建运行

1. 使用 DevEco Studio 打开本仓库根目录。
2. 等待 HarmonyOS SDK 与项目依赖同步完成。
3. 选择 `entry` 模块进行构建、运行或测试。
4. 具体设计、验收和构建记录见 `design.md` 与 `docs/` 目录。

## 主要目录

- `entry/src/main/ets/pages/`：首页、饮水、记账、统计、设置和数据管理页面。
- `entry/src/main/ets/components/`：进度、卡片、图表、导航和通用交互组件。
- `entry/src/main/ets/services/`：饮水、账单、统计、备份和偏好设置服务。
- `entry/src/main/ets/ledger/`：个人记账模块。
- `docs/`：设计、审核和交互验证记录。
- `submission/`：项目文档和参赛作品材料。
